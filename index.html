Featured Project

An end-to-end, config-driven data pipeline, built and documented in public

WA Parcel Reconciliation

Ingests parcel data from four Washington counties that each publish independently (different field names, projections, and geometry quality), conforms them to a common schema through dbt medallion models, and reconciles the result against the state's own statewide parcel layer, treating it as an answer key. Every remaining difference is classified and explained in both directions, including eight documented defects found in the answer key itself.

Airflow orchestrates ingest → dbt → export in isolated containers, skipping work unless a source has actually republished. The outputs are static artifacts: an interactive findings map served from GitHub Pages and public Tableau dashboards, every number in them generated by the same run.

1.5Msource records
96-99%agreement with the state layer
